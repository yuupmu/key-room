# 밴드 키보드 연습실

해커톤용 브라우저 앱입니다. 파일은 브라우저에서만 읽으며 서버에 업로드하지 않습니다.

## 실행

`dist/index.html`을 열거나 프로젝트 폴더에서 `python3 -m http.server 8000 --directory dist`를 실행한 뒤 `http://localhost:8000`에 접속하세요.

## 현재 동작

- MP3/WAV와 표준 MIDI(.mid/.midi) 파일을 클릭 또는 드래그해서 추가
- 오디오와 MIDI 동시 재생, 일시정지, 정지, 위치 이동, 속도 변경, 트랙별 음소거
- 오디오 파형과 MIDI 타임라인. 파일이 있는 트랙을 누르면 편집창이 열리고, [자료 추가]에서 파일을 교체
- 오디오 앞부분을 건너뛰는 비파괴 자르기로 MIDI와 시작점 맞추기
- MIDI 피아노롤에서 음표 선택 후 높이·시작 시각·길이·손 수정, 빈 칸 두 번 눌러 추가, 삭제·실행 취소, 전체 반음 조옮김, 편집한 MIDI 다운로드
- [보고 치기] 창에서 낙하 노트와 음명 피아노롤 보기

MIDI 소리는 브라우저의 간단한 신시사이저로 재생합니다. 오디오 자르기는 이 앱의 재생 시작점에만 적용되며 원본 파일은 그대로 유지됩니다.

## 다음 단계

자료 검색, 악보→MIDI 변환, 악보 표시·조옮김, 전자피아노 입력 연결.

## 참고

일반적인 MIDI 형식 0/1을 지원합니다. SMPTE 시간 형식과 형식 2는 아직 지원하지 않습니다. 왼손/오른손은 MIDI 트랙의 평균 음역으로 추정하므로 실제 손 구분과 다를 수 있습니다.
