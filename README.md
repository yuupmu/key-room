# 밴드 키보드 연습실

해커톤 1차 버전입니다. 파일은 브라우저에서만 읽으며 서버에 업로드하지 않습니다.

## 실행

`dist/index.html`을 열거나 프로젝트 폴더에서 `python3 -m http.server 8000 --directory dist`를 실행한 뒤 `http://localhost:8000`에 접속하세요.

## 현재 동작

- MP3/WAV와 표준 MIDI(.mid/.midi) 파일을 클릭 또는 드래그해서 추가
- 오디오와 MIDI 동시 재생, 일시정지, 정지, 위치 이동, 속도 변경, 트랙별 음소거
- 오디오 파형, MIDI 타임라인, 낙하 노트, 음명 표시 피아노롤
- MIDI 파일의 템포 및 음표 읽기. MIDI 소리는 브라우저의 간단한 신시사이저로 재생

## 다음 단계

자료 검색, 악보→MIDI 변환, 악보 표시·조옮김, 전자피아노 입력 연결. 관련 버튼은 이번 버전에서 구현 예정 안내를 보여줍니다.

## 참고

일반적인 MIDI 형식 0/1을 지원합니다. SMPTE 시간 형식과 형식 2는 아직 지원하지 않습니다. 왼손/오른손은 MIDI 트랙의 평균 음역으로 추정하므로 실제 손 구분과 다를 수 있습니다.
