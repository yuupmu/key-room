# Keyroom · 밴드 키보드 연습실

MP3/WAV 원곡과 MIDI를 함께 재생하고 편집하는 해커톤 웹 앱입니다. 재생용 오디오와 MIDI는 브라우저에서 처리합니다. 악보 변환을 선택하면 해당 악보 파일이 서버를 거쳐 OpenAI API로 전송됩니다.

## 요구 사항

- Node.js 20.12 이상
- npm
- 악보 PDF→MIDI 판독에 Poppler의 `pdftoppm` 실행 파일 (`PATH`에 포함)

악보 PDF 조판에는 `verovio`, `pdfkit`, `svg-to-pdfkit`과 한글 표기용 `@fontsource/noto-sans-kr`이 사용됩니다. 악보 이미지 분할에는 `sharp`, MIDI 재읽기에는 `midi-file`이 사용됩니다. `npm install` 후 실행하세요.

## VS Code에서 실행

1. 이 폴더를 VS Code로 엽니다.
2. 터미널에서 `npm install`을 실행합니다.
3. 같은 터미널에서 `npm run dev`를 실행합니다.
4. `http://127.0.0.1:3000`을 엽니다.

VS Code의 **실행 및 디버그 → Keyroom 개발 서버 → F5**로도 실행할 수 있습니다. `src/client`의 HTML, CSS, JavaScript를 수정한 뒤 브라우저를 새로고침하면 반영됩니다.

```bash
npm run dev      # 원본 프런트엔드를 제공하는 개발 서버
npm run check    # JavaScript 문법 확인
npm run build    # src/client → dist 복사
npm start        # 빌드된 dist를 제공하는 서버
```

`PORT`와 `HOST` 환경 변수로 로컬 서버 주소를 변경할 수 있습니다. `GET /health`는 서버 상태를 JSON으로 반환합니다.

## 현재 기능

- 처음에는 오디오·MIDI 트랙이 하나씩 보이며, 원하는 종류의 트랙을 추가·제거해 MP3/WAV와 MIDI(.mid/.midi)를 함께 재생
- 재생 위치, 속도, 원본·재생 BPM에 따른 MP3/WAV 및 MIDI 동시 속도 조절, 트랙별 음소거
- 연습 타임라인 옆 메트로놈 버튼: 4/4 첫 박 강세(A)와 나머지 박(B)을 반복하며, 파일 없이도 120 BPM으로 켜고 끌 수 있고 소리를 0~5배로 조절할 수 있음
- 오디오 시작 부분 건너뛰기로 MIDI와 싱크 맞추기
- 오디오 편집에서 MP3/WAV 트랙의 조를 반음씩 높이거나 낮추기(재생 길이 유지)
- MIDI 피아노롤에서 음표 추가·이동·길이 조절·삭제, 실행 취소, 전체 반음 조옮김, MIDI 다운로드
- 보고 치기 팝업의 낙하 노트·음명 피아노롤과 곡 전체 MIDI 탐색 막대
- USB/MIDI 전자피아노의 실시간 입력 음 표시, 원곡·가이드 MIDI와 함께 연주, 연주 기록 레이어 및 내 연주 MIDI 다운로드
- 노트북 키보드를 가상 피아노 건반으로 사용해 MIDI 장치 없이도 같은 실시간 표시·음원·연주 기록 이용
- 별도 악보 변환 칸에서 PNG/JPEG/PDF 악보의 AI 판독, 박자 검증, 양손 개별 MIDI 다운로드 및 MIDI 트랙 불러오기
- 코드 입력 또는 PNG/JPEG/PDF 코드 악보 판독 후 양손 연주 방식 3가지를 선택해 악보 PDF와 양손 개별 MIDI 생성
- 악보 변환 칸 아래에서 PDF 악보의 반복 구간을 연주 순서로 펼치거나 MIDI를 오선 악보로 조판해 PDF 다운로드
- 오른쪽 아래 곡 자료 검색에서 악보 판매처, 유튜브 영상, 출처가 있는 BPM·보컬 음역 확인

오디오 자르기와 BPM·조 조절은 앱의 재생에만 적용됩니다. 원본 오디오 파일은 바뀌지 않으며, 조를 바꿔도 오디오 재생 길이와 타임라인 위치는 유지됩니다. 오디오 조옮김은 브라우저의 Web Audio/WASM에서 Signalsmith Stretch로 처리하며, 첫 조옮김 때 처리기를 불러오느라 잠시 기다릴 수 있습니다. Web AudioWorklet을 지원하는 브라우저가 필요합니다. 가이드 MIDI는 로컬에 포함된 Salamander Grand Piano 샘플 30개를 Tone.Sampler로 재생하며, 샘플 사이의 음은 피치를 바꿔 냅니다. 첫 MIDI 재생 때 샘플을 불러오므로 잠시 기다릴 수 있습니다. 악보 표시는 아직 구현되지 않았습니다.

메트로놈은 재생 중에는 타임라인의 박자 그리드(MIDI 템포 변경 포함)에 맞춰 울립니다. 재생을 멈추거나 보고 치기·편집 화면을 열어도 켜짐 상태면 재생 BPM으로 계속 울리며, 연습 타임라인의 버튼을 다시 누르면 꺼집니다. 파일이 없을 때는 기본 120 BPM을 사용하며 상단 재생 BPM 입력으로 바꿀 수 있습니다. 메트로놈 옆 소리 슬라이더는 현재 음량을 1.0배로 두고 0~5.0배까지 조절합니다.

## 전자피아노 MIDI 연결

전자피아노를 USB 또는 USB-MIDI 인터페이스로 컴퓨터에 연결하고 전원을 켭니다. 데스크톱 Chrome/Edge에서 로컬 주소 `http://127.0.0.1:3000`을 열어 **MIDI 장치 연결**을 누르고 브라우저 권한을 허용한 뒤 입력 장치를 선택하세요. Web MIDI를 지원하지 않는 브라우저나 일반 HTTP 원격 주소에서는 연결되지 않습니다. 핫플러그 시 장치 목록이 갱신됩니다.

건반의 Note On/Off를 읽어 **지금 누르는 음**에 표시하고, 보고 치기의 건반·피아노롤에도 주황색으로 겹쳐 보여줍니다. 원곡 MP3/WAV와 가이드 MIDI를 넣고 재생하면 동시에 연주할 수 있습니다. 연결한 전자피아노의 입력 음도 브라우저에서 Salamander 피아노로 들립니다. 전자피아노 자체 스피커가 켜져 있으면 소리가 겹칠 수 있으므로 필요하면 기기 음량을 조절하세요. MIDI 입력 데이터는 서버로 전송하지 않습니다.

MIDI 장치가 없다면 **연주 입력**의 **demo**를 눌러 노트북 키보드 UI를 펼친 다음 **키보드 연주 켜기**를 누르세요. demo를 다시 누르면 UI가 접히고 키보드 연주도 꺼집니다. `A S D F G H J K L`은 `C4 D4 E4 F4 G4 A4 B4 C5 D5`(흰 건반), `W E T Y U O`는 그 사이의 검은 건반입니다. `Z/X`로 옥타브를 내리거나 올리고(`C2`~`C6`), `C/V`로 입력 세기를 조절합니다. 키를 누르는 동안 음이 울리고 화면 건반이 주황색으로 표시되며, 동시에 여러 음을 누를 수 있습니다. 보고 치기와 연주 기록도 물리 MIDI 입력과 동일하게 동작합니다. 한/영 전환과 관계없이 물리 키 위치를 사용하며, 입력 칸에서는 타이핑을 방해하지 않습니다. 브라우저 창을 벗어나면 눌린 음을 자동으로 놓습니다.

샘플 출처 및 라이선스는 [샘플 크레딧](src/client/assets/salamander/ATTRIBUTION.md)에 기록했습니다. Tone.js 15.0.4 배포 파일과 MIT 라이선스는 `src/client/tone.js`, `src/client/tone.LICENSE.md`에 포함되어 개발 서버에서도 로컬로 제공됩니다.

오디오 조옮김 처리기 [Signalsmith Stretch](https://github.com/Signalsmith-Audio/signalsmith-stretch)는 [MIT 라이선스](src/client/signalsmith-stretch.LICENSE.txt)입니다. `npm run build`가 설치된 패키지의 Web Audio 배포 파일을 `dist/signalsmith-stretch.mjs`로 복사하며, 개발 서버는 같은 패키지 파일을 제공합니다.

**연주 기록**을 누르면 재생 위치 기준으로 누른 음을 기록합니다(재생 중이 아니라면 재생도 시작). 일시정지·정지·장치 분리 시 기록이 끝나며, 기록한 음은 보고 치기 피아노롤과 MIDI 탐색 막대에 주황색으로 남습니다. **내 연주 MIDI**로 별도 파일을 저장하거나 **기록 지우기**로 비울 수 있습니다. 기록은 페이지를 닫으면 사라지므로 필요한 경우 MIDI를 다운로드하세요. 페달 CC, 건반 오디오 녹음 및 연주 채점은 지원하지 않습니다.

## 곡 자료 검색

서버에 `OPENAI_API_KEY`를 설정한 뒤 `npm run dev`로 실행합니다. 화면 오른쪽 아래 **곡 자료 찾기**를 열고 곡명과 아티스트를 입력합니다. 서버는 키를 브라우저에 공개하지 않고 OpenAI Responses API의 `gpt-5.6` 모델, `high` 추론, 웹 검색을 사용합니다. 확인된 직접 링크만 목록에 표시하며, BPM과 보컬 음역은 검색 출처가 확인된 경우에만 표시합니다. 직접 링크가 없는 경우에는 일반 검색 결과로 이동할 수 있습니다. 같은 제목의 다른 곡과 원곡·커버 버전은 구분해서 입력해 주세요. 검색 요청은 OpenAI API 사용량에 따라 비용이 발생합니다.

연습 타임라인 또는 보고 치기 팝업 아래의 MIDI 막대를 드래그하면 재생 위치가 이동합니다. **현재 위치에 플래그**를 누르면 시작점을 저장하고, 타임라인의 플래그 자체를 드래그해 위치를 조정할 수 있습니다. 플래그가 있을 때 재생 버튼이나 스페이스바로 다시 재생하면 그 위치에서 시작합니다. `Shift + 스페이스바`는 멈춘 위치에서 이어 재생합니다.

## 악보를 MIDI로 변환

서버를 실행하기 전에 프로젝트 루트의 `.env` 파일에 `OPENAI_API_KEY=발급받은_키`를 넣거나, 같은 터미널에서 환경 변수로 설정합니다. `.env`가 있으면 로컬 서버가 시작할 때 자동으로 읽습니다. 이미 서버가 실행 중이면 중지하고 다시 시작해야 새 코드와 키가 적용됩니다. 키가 담긴 `.env`는 Git에서 제외됩니다. 악보→MIDI 판독은 기본적으로 `gpt-6-astra`의 `high` 추론을 사용하며, 이 기능의 모델만 변경하려면 `OPENAI_SCORE_TO_MIDI_MODEL`을 설정합니다. 코드 악보 이미지의 코드 읽기는 별도의 `OPENAI_SCORE_MODEL` 설정을 사용합니다. 변환을 누르면 악보가 OpenAI Responses API로 전송됩니다. 최대 파일 크기는 8MB입니다.

서버는 PDF를 페이지별 이미지로 만들고 마디 경계를 찾은 뒤, 같은 시스템에서 양손이 함께 보이는 1~4마디씩 밀도에 따라 판독합니다. 출력 토큰 부족 시 구간을 절반으로 나누며, 박자 합·음역·누락 오류가 난 구간만 후보 JSON과 오류를 첨부해 재판독합니다. 구간 결과를 합친 다음에만 붙임줄과 공통 시간축을 검증하고 MIDI를 생성·재읽기합니다. 전체 500마디/80페이지까지 허용하며, 입력 파일은 최대 8MB입니다. 긴 판독은 OpenAI 백그라운드 응답과 화면의 진행 상태 조회를 사용하며 애플리케이션의 판독 시간 제한을 두지 않습니다. 입력하지 않은 문맥은 참고 이미지에서 확인하며 불확실한 경우 확정하지 않습니다.

각 구간의 최초 판독·재판독 JSON과 합친 초안은 서버의 OS 임시 디렉터리 `keyroom-score-transcriptions/<작업 ID>/`에 저장됩니다. 보존 위치는 `SCORE_TRANSCRIPTION_DIR`로 바꿀 수 있습니다. 원본 파일과 잘라낸 이미지는 저장하지 않으며, 운영 시 저장된 JSON의 보존/삭제 정책을 정해야 합니다. OpenAI 요청은 `store=false` 백그라운드 모드를 사용하므로 응답은 조회를 위해 일시적으로 보관됩니다. 진행 상태는 서버 메모리에 완료 후 1시간 유지되므로 서버를 재시작하면 조회를 재개할 수 없습니다. API의 상태·`incomplete_details.reason`·토큰 사용량·오류 코드는 서버 로그에 남지만 원본 이미지, 프롬프트, 음표 JSON, API 키는 로그에 남기지 않습니다.

각 성부의 음표·쉼표 길이가 박자표에 맞고, 붙임줄과 음높이가 유효한 경우에만 MIDI를 제공합니다. 판독이 불확실하거나 검증 오류가 남으면 해당 마디를 `?` 확인 화면에 남기고 원본 미리보기 옆에서 수기로 고칠 수 있습니다. 음표 입력은 `C4/4 D4/8 R/8`(4분음표·8분음표·8분쉼표), 화음은 `[C4,E4,G4]/2`, 점음표는 `F#4/4.`, 붙임줄은 `C4~/4`, 셋잇단음표는 `C4/8@3:2` 형식입니다. 정확한 마디 수와 박자표도 확인하고 누락된 마디는 직접 추가하세요. 빈칸·`?`가 남거나 길이 합이 맞지 않으면 MIDI 생성이 차단됩니다. 2단 피아노 악보는 상단 오선을 오른손, 하단 오선을 왼손으로 나눠 각각 MIDI 파일로 다운로드하고 연습 타임라인의 별도 트랙에 불러옵니다. 단일 오선은 오른손 파일만 생성하며, 3단 이상 악보의 손 분리는 지원하지 않습니다. 영상 인식만으로 모든 악보의 정확성을 보장할 수는 없으므로, 변환 후 원본 악보와 피아노롤을 대조해 주세요. 셋잇단음표와 일반적인 5·6·7잇단음표를 지원합니다. 도돌이표, 못갖춘마디, 카덴차처럼 해석이 필요한 악보는 자동 변환 대상에서 제외합니다.

## 코드를 악보, MIDI로 변환

**코드를 악보, MIDI로 변환**에서 코드를 직접 입력하거나 PNG/JPEG/PDF 코드 악보를 올려 **악보에서 코드 읽기**를 누릅니다. 파일 판독에만 `OPENAI_API_KEY`가 필요합니다. 판독 결과가 입력 칸에 나타나면 원본과 대조하고, 필요한 코드와 마디 경계를 수정한 뒤 연주 방식과 BPM을 선택해 생성합니다. 읽지 못했거나 지원하지 않는 코드 표기는 원래 위치에 `?`로 남고, 오른쪽 확인 필요 칸에서 수기로 입력할 수 있습니다. `?`가 남아 있으면 악보 생성은 진행되지 않습니다. PDF에는 양손 오선과 코드 기호가, 왼손 저음과 오른손 코드 구성음은 각각 별도 MIDI 파일에 들어갑니다. 두 MIDI는 연습 타임라인의 별도 트랙에도 불러옵니다.

입력 예: `F | C/E | Dm7 G7 | B♭M7`. `|` 또는 줄바꿈은 마디 경계이며, 한 마디에 여러 코드를 적으면 차례로 나눠 연주합니다. 한 줄에 코드만 공백으로 나열하고 마디 경계를 쓰지 않으면 각 코드를 한 마디로 봅니다. 마디선이 없는 가사·코드 악보도 이 기본 배치로 읽고 사용자가 변경 위치를 조정합니다. 현재 생성 예시는 **4/4 고정**이며, 원본 멜로디·가사·정확한 반주 리듬을 복원하는 기능은 아닙니다.

- 길게 누르기: 왼손 저음과 오른손 코드 구성음을 함께 유지
- 양손 번갈아 치기: 1·3박 왼손, 2·4박 오른손 화음
- 한 음씩 펼쳐 치기: 왼손 저음 유지, 오른손은 근음→3음→5음→3음

테스트 악보는 `test-fixtures/코드악보_for_BYPP_hackathon_demo.jpg`입니다. 이 이미지에 적힌 F, C/E, A-7, B♭M7, E♭M7(#11), Fsus4/C 등의 코드 표기와 슬래시 베이스·세 연주 패턴을 자동 테스트에 포함했습니다. 테스트는 실제 JPG 바이트가 판독 요청에 담기는지도 확인합니다. API 키가 없는 환경에서는 실제 AI OCR 정확도는 검증할 수 없으므로, 로컬 실행 시 이미지를 업로드해 판독 결과를 확인해 주세요.

코드 악보 카드의 밑줄 친 `demo`는 `코드악보_for_BYPP_hackathon_demo.jpg`를 파일 입력에 선택하고, 파일명을 눌러 원본 이미지를 다운로드할 수 있습니다. `악보에서 코드 읽기`를 누르면 API 호출 없이 샘플 제목과 코드 진행이 입력됩니다. 펼친 악보 카드의 `demo`는 원본 `Merry-go-round.pdf`를 파일 입력에 선택합니다. **악보 펼치기**를 누르면 약 1초 뒤 사전 제작된 `Merry-go-round-unfolded.pdf`의 다운로드 버튼이 나타납니다. 원본의 벡터 악보를 1–111마디 → 34–49마디 → 112–125마디 순으로 재배치했습니다. 원본의 인쇄된 마디 번호는 유지되며, 마지막 페이지에 경로 설명이 있습니다. 다른 PDF는 AI 판독을 사용하고 API 사용량에 따른 비용이 발생합니다. 업로드한 악보·MIDI도 표시된 파일명을 눌러 다시 다운로드할 수 있습니다.

## 연주 순서대로 펼친 악보

**악보 펼치기**에는 PDF 또는 MIDI(.mid/.midi)를 넣습니다. PDF는 페이지별로 나누어 OpenAI Responses API의 `gpt-5.6-sol`과 `xhigh` 추론으로 마디별 위치와 D.S./D.C., 세뇨, 코다, To Coda, Fine, 1·2번 엔딩, 반복기호를 찾습니다. 음표와 박자를 새로 판독해 조판하지 않습니다. 긴 판독은 백그라운드 요청으로 완료 상태를 조회하므로 몇 분 걸릴 수 있습니다. 마디 위치를 찾지 못한 페이지는 최대 두 번 더 확인하고, 마디 번호가 누락되거나 위치가 잘못되면 결과 생성을 중단합니다. 서버가 이동 경로를 계산한 뒤 원본 PDF의 마디 영역을 잘라 연주 순서대로 새 PDF에 배치합니다. 음표·조표·박자표·음자리표의 원본 모양이 복사됩니다.

MIDI는 음표와 MIDI 조표 메타데이터를 분석하고, 파일명에 곡명이 있으면 웹 검색 정보도 참고해 같은 AI 모델로 조성을 추론합니다. 다장조로 강제하지 않습니다. 음표는 일반·셋잇단 리듬으로 양자화해 오선에 배치합니다. PDF의 마디 위치나 이동 지시가 모호하면 결과를 내보내지 않습니다. 원본을 잘라 붙이는 방식이므로 반복·이동 표식은 출력에도 남을 수 있습니다. 두 형식 모두 최대 8MB이며, PDF는 최대 12페이지·160마디, MIDI는 최대 120마디를 지원합니다. 생성된 PDF는 원본과 대조해 주세요.

MIDI 트랙을 클릭하면 해당 피아노롤이 열립니다. 음표 본체를 드래그하면 시간과 음높이가 바뀌고, 끝을 드래그하면 길이가 바뀝니다. 빈 칸을 두 번 클릭하면 음표가 추가됩니다. 음표를 선택한 뒤 `Delete` 또는 `Backspace`로 삭제하고, `Ctrl/⌘ + Z`로 실행 취소합니다. 가운데 마우스 버튼을 누른 채 드래그하면 시간과 음역을 함께 이동합니다. `+`/`-` 또는 `Ctrl/⌘`+스크롤은 시간 축, `Alt +`/`Alt -`는 음역 축 확대·축소입니다. 드래그 중 `Alt`를 누르면 박자 그리드에 맞추지 않고 이동할 수 있습니다. 원본 BPM은 첫 번째 MIDI 파일에서 자동으로 가져오며 직접 입력할 수도 있습니다. 재생 BPM을 원본보다 낮추면 MP3/WAV와 MIDI가 함께 느려집니다. 상단 속도 선택은 이 BPM 비율에 추가로 적용됩니다. 타임라인과 MIDI 편집의 박자 그리드는 원본 MIDI의 템포 변경을 따릅니다. 상단의 편집 트랙 선택으로 불러온 MIDI 파일을 오갈 수 있습니다.

MIDI 형식 0/1을 지원합니다. SMPTE 시간 형식과 형식 2는 지원하지 않습니다. 보고 치기 화면의 음역 색상은 MIDI 트랙의 평균 음역으로 추정합니다. MIDI 다운로드에는 불러온 파일별 편집 트랙이 함께 들어갑니다. 현재 마디 표시는 4/4 기준입니다.
