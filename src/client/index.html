확인이 필요한 마디 ?

CHORDS TO SCORE / MIDI

코드를 악보, MIDI로 변환

코드만 알아도 양손 연주 예시를 만들 수 있어요. 코드 악보를 읽어 오거나 직접 입력한 뒤, 코드와 마디 배치를 확인해 주세요.

(demo) PNG · JPEG · PDF, 최대 8MB. 이미지 판독에 OpenAI API를 사용합니다.
| 또는 줄바꿈으로 마디를 나눕니다. 한 마디에 코드가 둘이면 Dm7 G7처럼 적으세요. 구분 없이 나열하면 코드 하나를 한 마디로 봅니다. 읽지 못한 코드는 ?로 표시됩니다.
